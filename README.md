## Real Bible App  

**A pure and efficient Bible app designed for speed and usability.**  

### Features  
- **Lightning-fast search** – Real-time results with up to 1000 verses.  
- **Infinite fingers navigation** – Flip between passages like a physical Bible.  
- **Cross-references** – Preloaded from TSK and OpenBible.info.  
- **Bookmarks & Notes** – Long-press any verse to interact with it.  
- **Offline Support** – Fully functional as a PWA (Progressive Web App).  
- **Mobile-First Design** – Optimized for touch navigation and quick access.  

### Installation (PWA)  
1. **Open the app**: [Real Bible App](https://thejusticeman.github.io/realbibleapp)  
2. **Install on Mobile**:  
   - On **Android (Chrome)**: Tap **"Add to Home Screen"** in the menu.  
   - On **iPhone (Safari)**: Tap the **Share** icon → **"Add to Home Screen."**  

### Usage  
- **Tap** a verse to read it.  
- **Long-press** a verse to bookmark, add notes, or see cross-references.  
- **Swipe and switch** between passages instantly.
